# Дисципліна «Організація баз даних та знань»

Даний репозиторій містить матеріали, лабораторні та контрольні роботи з навчальної дисципліни «Організація баз даних та знань».

## Предметна область
**Інформаційна система та база даних меблевого магазину.**

## Структура робіт
- `DB/` — загальні відомості та матеріали з дисципліни.
- `DB-CW-1/` — Контрольне завдання №1: розробка описів User Story та UseCase-моделі на базі PlantUML.
