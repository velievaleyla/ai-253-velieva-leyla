# Контрольне завдання №1: Проектування UseCase-моделі

## Дисципліна: «Організація баз даних та знань»

### Інформація про роботу
- **Тема:** Побудова діаграми прецедентів (UseCase) на основі опису предметної області та User Story
- **Предметна область:** База даних меблевого магазину
- **Студент:** Виконано згідно з вимогами навчальної програми

---

## Зміст каталогу `DB-CW-1`
1. [`UserStory.md`](./UserStory.md) — детальний опис предметної області, акторів (користувачів системи), вхідних/вихідних даних та повний перелік історій користувачів (User Stories).
2. [`UseCase.puml`](./UseCase.puml) — опис діаграми прецедентів мовою розмітки PlantUML з урахуванням прямокутника пакету ПП, акторів, узагальнень та прецедентів-отримувачів / передавачів інформації.

---

## Короткий опис розробленої моделі
- **Актори:**
  - `Користувач` (базовий абстрактний актор)
  - `Клієнт` (успадковує властивості Користувача)
  - `Співробітник` (базовий актор персоналу, успадковує властивості Користувача)
  - `Менеджер з продажу` (успадковує властивості Співробітника)
  - `Адміністратор` (успадковує властивості Співробітника)
- **Основні прецеденти:**
  - *Отримувачі інформації:* перегляд каталогу, перевірка термінів виготовлення та наявності, відстеження статусу замовлення, формування договорів/квитанцій, генерація аналітичних звітів.
  - *Передавачі інформації:* оформлення замовлень, оновлення статусів, керування даними персоналу, ведення бази постачальників і виробників.
